
# 🎁 Digital Gift Box

A web application that allows you to present an interactive, surprise-filled digital gift box to your loved ones. 

## ✨ Features
- **Interactive Design:** An engaging and animated gift box experience for users.
- **Real-Time Data:** Instant messages and status updates powered by Firebase Realtime Database.
- **Responsive Interface:** UI/UX-focused frontend design, fully compatible with mobile and desktop devices.
- **Easy Access:** Live and easily accessible structure deployed via GitHub Pages.

## 🛠️ Technologies Used
- HTML5, CSS3, JavaScript
- Firebase Realtime Database
- GitHub Pages (Deployment)
- Figma (UI/UX Design)
